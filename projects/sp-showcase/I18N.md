# Showcase internationalization

The showcase supports English (`en`) and Italian (`it`). A first visit always uses English, regardless of browser or system language. The AppBar selector switches language immediately, without navigation, reloads or recreating the active page. An explicit choice is stored as `sp-showcase.language` in localStorage; if storage is unavailable, switching still works for the current session. Unsupported saved values fall back to English.

## Translation catalogs

All messages are in `src/app/i18n/en.json` and `src/app/i18n/it.json`. Keys are grouped by page; shared messages are reused, and `meta.*` keys supply route metadata. Both catalogs must contain the same keys and matching `{{parameter}}` placeholders. Add new messages to both catalogs without renumbering existing keys.

Use `{{ 'home.002' | translate }}` for text and `[label]="'inputs.006' | translate"` for component captions. Import the standalone `TranslatePipe` into the page's component imports.

Existing dynamic demo labels and feedback can resolve through their original English or Italian text. The pipe also translates display fields in option/item collections, such as `[options]="countryOptions | translate"`. It preserves `value`, `id`, disabled flags, icons, URLs, callbacks and the source objects, and caches translated collection identities between checks. User-entered input values and technical values in code are echoed unchanged.

Parameterized `feedback.*` messages translate composed demo feedback and modal titles. The original and translated forms are recognized, so a message already shown on screen follows subsequent language changes as well.

## Scope and invariants

- No library implementation or package dependency was changed.
- The active demo instance, selections, input values and open dialogs survive language changes.
- Existing styles and markup structure are retained; the AppBar language selector has its own local styling.
- Literal HTML, TypeScript and SCSS code examples are intentionally unchanged, including any sample text inside them.
- `TranslateLabelsDirective` is restricted to the showcase shell. It localizes rendered accessibility attributes for library controls that have fixed captions, including dynamically inserted dialogs. It observes only child insertion and accessible-label changes, disconnects on destruction, and does not change component state, event handling, visual content or code samples.
- The document language, Open Graph locale, browser title, search description and social title/description follow the selected language. Initial HTML metadata is English.

## Verification

Run the focused tests from the repository root:

```bash
ng test sp-showcase --watch=false --browsers=ChromeHeadless --include="projects/sp-showcase/src/app/i18n/*.spec.ts"
npm run build:showcase
```

The tests cover catalog parity and parameters, English defaults, saved preferences, blocked storage, stable demo data, composed feedback, OnPush updates, accessibility captions and route metadata. Browser verification also checks all 23 routes in both languages and preservation of the existing code examples.
